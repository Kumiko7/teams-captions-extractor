# teams-captions-extractor
Pulls automated captions from Teams and displays them in a local webpage, allowing for copy/paste, automatically saving transcripts as logs, and highlighting relevant lines.

1. Install the requirements: `pip install -r requirements.txt`
2. Run teams_captions.bat
3. A webpage showing the live captions from Teams will open.
4. Logs will be automatically saved in a /logs folder.
5. Edit config.py for keywords to highlight (created from config.example.py on first run).

Live captions must be turned on in the Teams meeting. The web page is only reachable from this computer.
